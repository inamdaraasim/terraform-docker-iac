# Terraform Docker Infrastructure

## Objective
Provision a local Docker container using Terraform.

## Tools
- Ubuntu Linux
- Docker Engine
- Terraform
- Nginx

## Steps
1. Install Terraform.
2. Configure Docker provider.
3. Run terraform init.
4. Run terraform validate.
5. Run terraform plan.
6. Run terraform apply.
7. Verify Docker container.
8. Check Terraform state.
9. Run terraform destroy.

## Outcome
Successfully created and destroyed
a Docker container using Terraform.
